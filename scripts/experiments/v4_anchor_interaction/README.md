# V4 Anchor Interaction Ablation V1

Frozen base: `2e8afae7a74a1a4138f45e49dc8add83df6b579e`. Production V4 forward, conditions, Motion Decoder, Dataset, fixed initial RBF and objective are imported unchanged.

G0 is the original class. G1 adds two geometry-initialized AnchorInteraction layers before cross block0; G2 adds the SAME two layers after cross block1. Both exclude own-index keys and retain residuals and a zero null value for the single-valid-anchor case. G3 replaces each of the two cross blocks with anchor-query-only hybrid attention. Controllers occupy keys0–59, anchors60–187, null188. This ordering preserves the original rollout's first60 controller-weight slice; all189 keys share one softmax, no controller-subset renormalization. Anchor keys are the current layer's features and live predicted positions, using fixed initial anchor identities. Added key type vectors start at zero. Learned score coefficients can reverse distance preference.

Common modules are explicitly copied from a seed42 G0, not matched by constructor RNG consumption. New modules use seed4201, the original geometry initialization, and default Linear initialization elsewhere. A2A residual outputs are not zeroed; the original zero motion output head keeps initial positions equal to Copy. G1/G2 have identical added tensors. Checkpoint config contains interaction mode and rejects cross-mode resume; G0 config remains identical to historical V4.

All-window 1544 train /102 val, original strides1/5, H10 interval1, seed42, AdamW lr1e-4 wd1e-4, global clip1, float32 TF32off. Four runs each1600 successful updates, shuffled window passes frozen before fitting and identical across groups. Original CD+RGB+0.1Alpha only. Full-validation episode-equal joint chooses best every200; lowest ordinary CD is a separate checkpoint. Initial checkpoint is not a selection candidate. Contact52 is diagnostic only. No test GS is loaded. The six specified windows are frozen before training; no result-dependent sample selection.

Run CPU tests from repository root: `python -B -m unittest discover -s scripts/tests -t . -v`.

Freeze data/config on CPU: `python -B -m scripts.experiments.v4_anchor_interaction.run --root OUTPUT --expected-sha SHA --stage freeze`. OUTPUT must not exist. Then run `execute.sh` in the authorized Slurm tmux shell with SOURCE, EXPECTED_SHA and OUTPUT_ROOT. It gates all four models using two real rendering optimizer updates and exact checkpoint restore each; smoke states are discarded. Only after all smoke cases pass does it train G0–G3 sequentially and perform final evaluation. No automatic retries or changed budget. Errors retain a failure JSON and stop this pipeline; no other process is canceled.

Final report includes best_joint, lowest_cd, last on full102 and contact52; best-model action freeze and valid tactile zero diagnostics; raw per-window/per-horizon errors; fixed initial Near/Far regions (lowest/highest quarter distance to valid active controllers at t0), one-way region-to-GT nearest distances, proper Kabsch residual relative to initial predicted identities, neighbors, attention masses and full matrices at fixed cases. No GT material IDs are inferred. Near/Far equality is not a quality target, and attention is not physical force/contact probability.

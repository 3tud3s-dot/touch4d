# Experiment tools and historical versions

Tools reuse `scripts.training` and the shared data infrastructure. They are diagnostics, not alternative production model packages.

- `fixed_window/fixed_fit.py`: exact `(episode, start)` selection, frozen 400-update protocol, metrics, safe checkpoint recovery and visualization. Entry: `python -m scripts.training.train --protocol fixed400 ...`; evaluation: `python -m scripts.training.evaluate --split fit ...`. Preserve the reviewed config/contract or use the explicitly labelled diagnostic mode. Do not substitute the first two dataset windows.
- `oracle/oracle.py`: Oracle-Latent / Oracle-Anchor capacity probes with the original isotropic P1a decoder; target-optimized variables are not causal predictors.
- `oracle/oracle_fit.py`: `python -m scripts.experiments.oracle.oracle_fit --help`. The old `scripts.training.oracle_fit` command delegates here. It retains its original budget, initialization checks, target-information warning and independent output directory.
- `archive/`: version indexes only. Use an external Git worktree at the documented commit for original sources, command paths and environment requirements; never overlay historical sources on the current checkout.
